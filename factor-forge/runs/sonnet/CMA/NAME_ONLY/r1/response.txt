This script computes CMA as the average of the two low-investment (conservative) portfolios minus the average of the two high-investment (aggressive) portfolios: CMA = ½(Small LoINV + Big LoINV) − ½(Small HiINV + Big HiINV). It uses only the first section of the file (value-weighted monthly returns), stops at the first blank line after the data starts, and skips any month with a missing value (-99.99 or -999). I have not run it against the full file.

```python
import pandas as pd

rows = []
started = False
in_section = False
with open("6_Portfolios_ME_INV_2x3.csv") as f:
    for line in f:
        s = line.strip()
        if not in_section:
            if "Average Value Weighted Returns" in s and "Monthly" in s:
                in_section = True
            continue
        if not s:
            if started:
                break
            continue
        parts = [p.strip() for p in s.split(",")]
        if len(parts[0]) == 6 and parts[0].isdigit():
            started = True
            try:
                vals = [float(x) for x in parts[1:7]]
            except ValueError:
                continue
            rows.append([int(parts[0])] + vals)
        elif started:
            break

df = pd.DataFrame(rows, columns=["date", "sl", "sm", "sh", "bl", "bm", "bh"])
for c in ["sl", "sm", "sh", "bl", "bm", "bh"]:
    df = df[(df[c] > -99) ]
df["value"] = (df["sl"] + df["bl"]) / 2 - (df["sh"] + df["bh"]) / 2
df[["date", "value"]].to_csv("output.csv", index=False)
```
