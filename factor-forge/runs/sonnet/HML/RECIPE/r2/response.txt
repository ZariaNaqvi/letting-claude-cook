The script reads the file line by line and finds the first table by locating the header line that contains "Value Weighted Returns -- Monthly". It then takes the next line as the column header and parses rows until the first line that doesn't start with a 6-digit date. Missing values (-99.99 or -999) are set to NaN, and those months are dropped from the output.

HML is computed as 0.5*(SMALL HiBM + BIG HiBM) - 0.5*(SMALL LoBM + BIG LoBM). I did not run it against the full file.

```python
import numpy as np
import pandas as pd

rows = []
with open("6_Portfolios_2x3.csv", "r", encoding="latin-1") as f:
    lines = f.read().splitlines()

start = None
for i, l in enumerate(lines):
    if "Average Value Weighted Returns" in l and "Monthly" in l:
        start = i
        break

header = [h.strip() for h in lines[start + 1].split(",")]
for l in lines[start + 2:]:
    parts = [p.strip() for p in l.split(",")]
    if not parts or not (len(parts[0]) == 6 and parts[0].isdigit()):
        break
    rows.append(parts[:len(header)])

df = pd.DataFrame(rows, columns=["date"] + header[1:])
df["date"] = df["date"].astype(int)
cols = header[1:]
for c in cols:
    df[c] = pd.to_numeric(df[c], errors="coerce")
    df.loc[(df[c] <= -99.99), c] = np.nan

hml = 0.5 * (df["SMALL HiBM"] + df["BIG HiBM"]) - 0.5 * (df["SMALL LoBM"] + df["BIG LoBM"])
out = pd.DataFrame({"date": df["date"], "value": hml}).dropna()
out["date"] = out["date"].astype(int)
out.to_csv("output.csv", index=False)
```
