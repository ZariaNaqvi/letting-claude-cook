The script reads the file line by line and takes only the first table, which is the value-weighted monthly block. It finds the header line containing "Average Value Weighted Returns -- Monthly" and then reads the column header on the next line. It keeps rows whose first field is a 6-digit YYYYMM and stops at the first blank line or non-matching line after data has started.

Missing values (-99.99 or -999) are set to NaN, so any month with a missing needed column gets a NaN result. I drop those rows rather than write them.

HML = 0.5*(SMALL HiBM + BIG HiBM) - 0.5*(SMALL LoBM + BIG LoBM). I look the columns up by name in the header, which is `,SMALL LoBM,ME1 BM2,SMALL HiBM,BIG LoBM,ME2 BM2,BIG HiBM`.

```python
import pandas as pd
import numpy as np

rows = []
header = None
started = False
with open("6_Portfolios_2x3.csv", "r", errors="ignore") as f:
    lines = f.read().splitlines()

i = 0
while i < len(lines):
    if "Average Value Weighted Returns" in lines[i] and "Monthly" in lines[i]:
        header = [h.strip() for h in lines[i + 1].split(",")]
        i += 2
        break
    i += 1

while i < len(lines):
    line = lines[i].strip()
    i += 1
    if not line:
        if started:
            break
        continue
    parts = [p.strip() for p in line.split(",")]
    if len(parts[0]) == 6 and parts[0].isdigit():
        started = True
        rows.append(parts)
    elif started:
        break

df = pd.DataFrame(rows, columns=header[:len(rows[0])])
date_col = df.columns[0]
for c in df.columns[1:]:
    df[c] = pd.to_numeric(df[c], errors="coerce")
    df.loc[df[c] <= -99.0, c] = np.nan

val = 0.5 * (df["SMALL HiBM"] + df["BIG HiBM"]) - 0.5 * (df["SMALL LoBM"] + df["BIG LoBM"])
out = pd.DataFrame({"date": df[date_col].astype(int), "value": val})
out = out.dropna().reset_index(drop=True)
out.to_csv("output.csv", index=False)
```
