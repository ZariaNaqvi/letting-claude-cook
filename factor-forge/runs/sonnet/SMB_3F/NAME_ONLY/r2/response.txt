This script reads only the first section of the file (Average Value Weighted Returns, Monthly) and stops at the first blank line or new header after the data. It computes SMB as the average of the three small portfolios minus the average of the three big portfolios, which is the 3-factor definition:

SMB = 1/3 (Small Lo + Small BM2 + Small Hi) − 1/3 (Big Lo + Big BM2 + Big Hi)

Months with a missing value (-99.99 or -999) in any of the six portfolios are dropped. I did not run it against the full file.

```python
import csv

rows = []
in_section = False
with open("6_Portfolios_2x3.csv", "r", errors="ignore") as f:
    for line in f:
        s = line.strip()
        if not in_section:
            if s.startswith("Average Value Weighted Returns") and "Monthly" in s:
                in_section = True
            continue
        if not s:
            if rows:
                break
            continue
        parts = [p.strip() for p in s.split(",")]
        if len(parts) < 7:
            if rows:
                break
            continue
        d = parts[0]
        if not (d.isdigit() and len(d) == 6):
            if rows:
                break
            continue
        try:
            vals = [float(x) for x in parts[1:7]]
        except ValueError:
            continue
        rows.append((int(d), vals))

out = []
for d, v in rows:
    if any(x <= -99.99 or x == -999 for x in v):
        continue
    small = (v[0] + v[1] + v[2]) / 3.0
    big = (v[3] + v[4] + v[5]) / 3.0
    out.append((d, round(small - big, 4)))

with open("output.csv", "w", newline="") as f:
    w = csv.writer(f)
    w.writerow(["date", "value"])
    for d, x in out:
        w.writerow([d, x])
```
