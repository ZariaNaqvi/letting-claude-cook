The script reads the file line by line and keeps only the first table. It starts after the header line containing "Average Value Weighted Returns -- Monthly" and ends at the first line that is not a 6-digit date row.

Each data row is split on commas. The date must be a 6-digit integer and there must be 7 fields. The columns are SMALL LoOP, ME1 OP2, SMALL HiOP, BIG LoOP, ME2 OP2, BIG HiOP.

Missing values are -99.99 or -999. Any month with a missing value in one of the four portfolios used is skipped, because the result would be wrong.

RMW is 0.5*(SMALL HiOP + BIG HiOP) - 0.5*(SMALL LoOP + BIG LoOP). Values are rounded to 4 decimals.

```python
import re

rows = []
started = False
with open("6_Portfolios_ME_OP_2x3.csv", "r", errors="ignore") as f:
    for line in f:
        s = line.strip()
        if not started:
            if "Average Value Weighted Returns" in s and "Monthly" in s:
                started = True
            continue
        if not s:
            if rows:
                break
            continue
        parts = [p.strip() for p in s.split(",")]
        if re.fullmatch(r"\d{6}", parts[0]) and len(parts) >= 7:
            try:
                vals = [float(x) for x in parts[1:7]]
            except ValueError:
                continue
            rows.append((int(parts[0]), vals))
        else:
            if rows:
                break

out = []
for d, v in rows:
    sl, _, sh, bl, _, bh = v
    if any(x <= -99.0 for x in (sl, sh, bl, bh)):
        continue
    out.append((d, round(0.5 * (sh + bh) - 0.5 * (sl + bl), 4)))

with open("output.csv", "w") as f:
    f.write("date,value\n")
    for d, val in out:
        f.write(f"{d},{val}\n")
```
