This script builds RMW from the value-weighted monthly section of the file only, using Ken French's definition: the average of the two robust-profitability portfolios minus the average of the two weak-profitability portfolios.

RMW = ½ (Small HiOP + Big HiOP) − ½ (Small LoOP + Big LoOP)

It stops reading at the first non-data line after that section, so the equal-weighted and annual sections are ignored. Months with a missing value (-99.99 or -999) in any of the four portfolios used are dropped. I have not run it against the full file.

```python
import re
import pandas as pd

rows = []
in_section = False
started = False
with open("6_Portfolios_ME_OP_2x3.csv", "r", errors="ignore") as f:
    for line in f:
        s = line.strip()
        if not in_section:
            if "Average Value Weighted Returns" in s and "Monthly" in s:
                in_section = True
            continue
        parts = [p.strip() for p in s.split(",")]
        if re.fullmatch(r"\d{6}", parts[0] or "") and len(parts) >= 7:
            started = True
            try:
                vals = [float(x) for x in parts[1:7]]
            except ValueError:
                continue
            rows.append([int(parts[0])] + vals)
        else:
            if started:
                break

df = pd.DataFrame(rows, columns=["date", "sl", "sm", "sh", "bl", "bm", "bh"])
for c in ["sl", "sm", "sh", "bl", "bm", "bh"]:
    df.loc[df[c] <= -99, c] = float("nan")
df["value"] = (df["sh"] + df["bh"]) / 2 - (df["sl"] + df["bl"]) / 2
out = df[["date", "value"]].dropna()
out["date"] = out["date"].astype(int)
out.to_csv("output.csv", index=False)
```
