Momentum (UMD) is built as the average of the two high prior-return portfolios minus the average of the two low prior-return portfolios:

Mom = ½ (Small High + Big High) − ½ (Small Low + Big Low)

How the script handles the file:

- **Which data it uses.** It reads only the first block of the file, "Average Value Weighted Returns -- Monthly". The later blocks (equal-weighted, annual, firm counts and others) are ignored.
- **Which columns it uses.** The six columns are taken by position, not by header name.
- **Missing values.** Months with a missing marker (-99.99 or -999) in any of the four portfolios used are dropped.
- **Rounding.** The input portfolio returns are already rounded to 2 decimals. The factor computed from them can therefore differ from French's published series by about 0.01.

```python
import csv
import re
import numpy as np
import pandas as pd

FNAME = "6_Portfolios_ME_Prior_12_2.csv"

with open(FNAME, "r", encoding="latin-1") as f:
    lines = f.read().splitlines()

# Locate first monthly value-weighted block
start = None
for i, ln in enumerate(lines):
    if "Value Weighted Returns" in ln and "Monthly" in ln:
        start = i
        break
if start is None:
    # fallback: first header line beginning with ','
    for i, ln in enumerate(lines):
        if ln.strip().startswith(","):
            start = i - 1
            break

# header line is next line starting with ','
hdr_idx = start + 1
while not lines[hdr_idx].strip().startswith(","):
    hdr_idx += 1

rows = []
for ln in lines[hdr_idx + 1:]:
    s = ln.strip()
    if not s:
        break
    parts = [p.strip() for p in s.split(",")]
    if not re.fullmatch(r"\d{6}", parts[0]):
        break
    try:
        vals = [float(x) for x in parts[1:7]]
    except ValueError:
        continue
    if len(vals) < 6:
        continue
    rows.append([int(parts[0])] + vals)

df = pd.DataFrame(rows, columns=["date", "SL", "SM", "SH", "BL", "BM", "BH"])
for c in ["SL", "SM", "SH", "BL", "BM", "BH"]:
    df.loc[(df[c] <= -99.99) | (df[c] == -999), c] = np.nan

df["value"] = 0.5 * (df["SH"] + df["BH"]) - 0.5 * (df["SL"] + df["BL"])
out = df[["date", "value"]].dropna().copy()
out["date"] = out["date"].astype(int)
out["value"] = out["value"].round(6)
out = out.drop_duplicates("date").sort_values("date")
out.to_csv("output.csv", index=False)
```
