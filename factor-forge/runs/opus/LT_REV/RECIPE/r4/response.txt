The script reads only the first monthly value-weighted table and computes LT_Rev as Low minus High:

```python
import csv
import numpy as np
import pandas as pd

FNAME = "6_Portfolios_ME_Prior_60_13.csv"

with open(FNAME, "r", encoding="latin-1") as f:
    lines = f.read().splitlines()

# Locate the first block: Average Value Weighted Returns -- Monthly
start = None
for i, ln in enumerate(lines):
    if "Average Value Weighted Returns" in ln and "Monthly" in ln:
        start = i
        break
if start is None:
    raise RuntimeError("Value-weighted monthly block not found")

# Header line follows (first non-empty line starting with comma)
j = start + 1
while j < len(lines) and not lines[j].strip():
    j += 1
header = [h.strip() for h in next(csv.reader([lines[j]]))]
j += 1

rows = []
while j < len(lines):
    ln = lines[j].strip()
    if not ln:
        break
    parts = [p.strip() for p in next(csv.reader([ln]))]
    d = parts[0]
    if not (d.isdigit() and len(d) == 6):
        break
    rows.append(parts)
    j += 1

cols = ["date"] + header[1:]
df = pd.DataFrame([r[:len(cols)] for r in rows], columns=cols)
df["date"] = df["date"].astype(int)
for c in cols[1:]:
    df[c] = pd.to_numeric(df[c], errors="coerce")
    df.loc[df[c] <= -99.99, c] = np.nan

def find(name):
    key = name.upper().replace(" ", "")
    for c in cols[1:]:
        if c.upper().replace(" ", "") == key:
            return c
    raise KeyError(name)

sl = find("SMALL LoPRIOR")
sh = find("SMALL HiPRIOR")
bl = find("BIG LoPRIOR")
bh = find("BIG HiPRIOR")

df["value"] = 0.5 * (df[sl] + df[bl]) - 0.5 * (df[sh] + df[bh])
out = df[["date", "value"]].dropna().sort_values("date")
out = out.drop_duplicates("date")
out["value"] = out["value"].round(6)
out.to_csv("output.csv", index=False)
```

The script does the following:
- **Finding the table:** it locates the "Average Value Weighted Returns -- Monthly" block and reads rows until the block ends, at the first blank line or the first row whose date is not six digits.
- **Missing values:** any value of -99.99 or -999 is treated as missing.
- **Matching columns:** portfolio columns are matched by name, ignoring spaces and letter case.
- **Output:** months with missing inputs are dropped, so `output.csv` has one row per month the data supports, sorted by date.
