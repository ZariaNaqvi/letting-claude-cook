SMB in the Fama-French 3-factor model comes only from the 2x3 size–book-to-market sort:

SMB = 1/3 (Small LoBM + Small BM2 + Small HiBM) − 1/3 (Big LoBM + Big BM2 + Big HiBM)

The script works as follows:

- **Which data it uses:** it reads only the value-weighted monthly block, "Average Value Weighted Returns -- Monthly". It stops at the first line that is not a `YYYYMM` row, so the equal-weighted and annual blocks are skipped.
- **Missing values:** entries of -99.99 or -999 are treated as missing. Any month with a missing value is dropped.
- **Rounding:** the result is kept to 6 decimals rather than French's published 2 decimals. Matching his 2-decimal figures would mean rounding a value computed from his already-rounded inputs, which can be off by 0.01. Keeping more decimals keeps the error below 0.005.

```python
import re
import numpy as np
import pandas as pd

FNAME = "6_Portfolios_2x3.csv"

with open(FNAME, "r", encoding="utf-8", errors="replace") as f:
    lines = f.read().splitlines()

# locate the value-weighted monthly section
start = None
for i, line in enumerate(lines):
    if "Average Value Weighted Returns" in line and "Monthly" in line:
        start = i
        break
if start is None:
    raise RuntimeError("Value-weighted monthly section not found")

# header line follows
hdr_idx = start + 1
while hdr_idx < len(lines) and lines[hdr_idx].strip() == "":
    hdr_idx += 1
header = [h.strip() for h in lines[hdr_idx].split(",")]
cols = header[1:]

rows = []
for line in lines[hdr_idx + 1:]:
    s = line.strip()
    if not s:
        if rows:
            break
        continue
    parts = [p.strip() for p in s.split(",")]
    if not re.fullmatch(r"\d{6}", parts[0]):
        break
    vals = []
    for p in parts[1:1 + len(cols)]:
        try:
            v = float(p)
        except ValueError:
            v = np.nan
        if v <= -99.99 + 1e-9 or v == -999:
            v = np.nan
        vals.append(v)
    rows.append([int(parts[0])] + vals)

df = pd.DataFrame(rows, columns=["date"] + cols)

def find_col(size_key, bm_key):
    for c in cols:
        cu = c.upper()
        if size_key in cu and bm_key in cu:
            return c
    raise KeyError((size_key, bm_key))

# small portfolios: SMALL/ME1 ; big: BIG/ME2
small = [c for c in cols if ("SMALL" in c.upper() or "ME1" in c.upper())]
big = [c for c in cols if ("BIG" in c.upper() or "ME2" in c.upper())]
if len(small) != 3 or len(big) != 3:
    small = cols[0:3]
    big = cols[3:6]

df["value"] = df[small].mean(axis=1, skipna=False) - df[big].mean(axis=1, skipna=False)
out = df[["date", "value"]].dropna()
out["date"] = out["date"].astype(int)
out["value"] = out["value"].round(6)
out = out.sort_values("date").drop_duplicates("date")
out.to_csv("output.csv", index=False)
```
